🤖 AI Trainee Platform

Live Demo: https://ai-trainee-platform.vercel.app/

A modern, highly interactive AI Mock Interview Platform built to help candidates prepare for technical roles. This project was developed as a submission for my IBM Internship, showcasing modern frontend development, state management, and algorithmic data processing.

🚀 Overview

The AI Trainee Platform simulates realistic technical interviews without relying on costly external APIs. It utilizes a vast, locally stored dataset of industry-standard questions and employs a custom ATS (Applicant Tracking System) grading algorithm to evaluate user responses based on domain-specific vocabulary and declared tech stacks.

✨ Key Features

Role-Specific Simulations: Tailored interview tracks for Software Engineers, Data Analysts, Product Managers, UX Designers, and more.

Honest ATS-Style Evaluation: The grading engine analyzes user transcripts for keyword density, tech-stack utilization, and overall effort, providing realistic, actionable feedback.

Performance Analytics: A comprehensive dashboard that tracks interview history, calculates average scores, and visualizes performance trends over time.

Data Portability: One-click export functionality allows users to download their entire interview history as an Excel/CSV file.

Cyberpunk / Neon UI: A beautifully crafted, responsive user interface utilizing modern design tokens, glassmorphism, and Tailwind CSS v4.
